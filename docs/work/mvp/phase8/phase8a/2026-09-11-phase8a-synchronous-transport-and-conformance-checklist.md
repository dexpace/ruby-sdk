## Deviations from the plan

Departures from the plan's text, each with its reason. None lowers, disables or narrows a gate. Items
1–14 are where the built tree overrode the plan's assumptions, in the order the brief's as-built list
gives them; 15–36 are this build's, 37–38 review round 1's, 39–42 review round 2's, 43 review round 3's and 44
review round 4's. The ones that touch public behaviour or a statement the design makes are also the
as-built ledger rows `P8-51`–`P8-65`.

1. **Task 23 Step 1 and Task 3 Steps 3–6 were already built by phase 0** — `clean_bundle_check` writes the `dexpace-core` path line and the denylist carries `socket`'s per-gem scope — and neither was re-applied; Task 23's own contribution is the scratch `BUNDLE_PATH` (item 33).
2. **`require "zlib"` and `require "tempfile"` are absent from the adapter's `lib/`** — `zlib` is `net/http`'s own require and the allowlist denies it to the adapter; `Failures` names `Zlib::Error` in a comment only.
3. **`tempfile` joined the allowlist for every gem** (Task 3), with `TRANSPORT-28`'s reason, and the gate's positive-control fixture requires it; a separate `tempfile.rb` fixture was written and then folded into `allowed.rb`, because the gate suite's class was at the length cap.
4. **The three core pins the two new constants moved** were flipped on the code branch (nine keys, nine in the downstream wiring test, ten events); the registration invalidated four in-process bare-require pins, which became child-process assertions (Task 2), then moved to `core/transport_bare_require_test.rb` over the shared `BareRequire` helper when `transport_test.rb` crossed the length cap.
5. **`Model.required!(name, value)`, `Body.bytes`, `Pipeline.standard(builder)` with no `builder:` keyword, `Response.build` accepting a String protocol and an Integer status, `DexpaceTestCase` for the driver class** — the plan's stand-in spellings replaced by the real ones throughout.
6. **`Events::TRANSPORT_HEADER_DROPPED` lives in `instrumentation/keys.rb`**, 5b's one-file precedent, not a new `events.rb`.
7. **The pump's carried raise is `raise error, cause: payload`** (and `cause: nil` when `Failures.wrap` handed the payload back unchanged, because Ruby refuses an error as its own cause), never a bare `raise`; the test asserts the cause is present and is not the unrelated in-flight exception.
8. **`Adapter#call` rescues into a named binding** (`rescue ::StandardError => error`), which `Failures.wrap` receives; the plan's `$!` spelling and its "no `=> e`" argument are moot once the binding is used.
9. **No `DexpaceConformanceTestCase`**; the driver class inherits `DexpaceTestCase`, so a leaked fixture thread fails the assertion that leaked it.
10. **Local doubles in each gem's `test/support/`** — `RawWireTransport`, `NonConformingTransport`, `StubTransport`, `AssertionProbe` in the conformance gem; `NetHTTPRecordingSink`, `AdapterFixtures` and, from review round 2, `NetHTTPHermeticProxy` in the adapter gem — never a reach into core's, and never a name core's `test/support/` already defines; the design's decline of the fake move stands (Postponed work).
11. **`Configuration::EMPTY` reads the process environment**, so every proxy-route test builds `Configuration.build(env_source: Sources.from_hash(…))`, and the two tests that drive the whole adapter go through `Dexpace.configure { |b| b.override(key, …) }` with `reset_config!` in an `ensure` — overriding all three of `HTTP_PROXY`, `HTTPS_PROXY` and `NO_PROXY` since review round 2 (item 40).
12. **The response-pump raise site and the borrowed-client refusal spell their messages as built**; no test matches a `URI` or net-http message.
13. **`RuboCop`'s findings drove four shapes**: `extend self` in every helper module (`Style/ModuleFunction`), no `**` splat in any `lib/` (`Dexpace/NoKeywordSplat`), the `ROWS` tables and `Checks` extraction under `Metrics/ModuleLength`, and the inline `Metrics/ClassLength` disable with its reason on `Adapter` and `ResponsePump` (core's `Registry` and `AsyncBearerStamper` precedent).
14. **`sig/` is one-for-one with `lib/`, private constants included**, each private mirror opening with `hooks.rbs`'s comment; the ivars that hold a `Net::HTTP`, a `TCPServer` or a `Tempfile` are `untyped`.
15. **The producer waits for the head to be adapted before it reads the body** (`P8-51`). R4's sequence — copy the headers, delete an unparseable `content-length` from the native head, then let `read_body` run — has a race the design did not name: the producer pushes the head and, without a handshake, reaches `read_body` before the consumer's `ResponseMapper` has deleted the header, and `read_body_0` raises `Net::HTTPHeaderSyntaxError` on the producer's thread (`TRANSPORT-27`'s conformance assertion, red on the first real run). `head_or_raise` now takes a block, yields the head, and resumes the producer through a `Queue` when the block returns or raises; the block-less form resumes it at once.
16. **The cancellation subscription is the pump's and lives for the response's life** (`P8-52`), not `#call`'s: the plan detached it in `dispatch`'s `ensure`, after which a cancel under a blocked body read would have done nothing until the read failed on its own. The pump subscribes after its thread exists (an already-cancelled token fires the hook at once) and detaches in `#release`; `Adapter#call` checks the token first, so an already-cancelled call never opens a socket — and since review round 2 the pump asks the token itself before starting a producer (item 39, `P8-64`).
17. **A pop that finds the queue closed is classified through the token** — `CancelledError` when it is cancelled, otherwise `ClosedError` (use after close) or, before any head, a retryable `TransportError` — and a closed queue is end of stream only when the pump is not closed (`P8-54`); the plan's `else raise EndOfStreamError` would have read a close under a read as a clean end of stream.
18. **The permit is returned by the producer's `ensure`, once the client is free** (`P8-53`), not by `#release` after a bounded join: a producer still holding the caller's socket past the join deadline must keep the next borrowed call waiting, or two exchanges share one `Net::HTTP`. The native request is mapped before the permit is taken, so a refused header holds nothing up.
19. **The producer never `break`s out of `read_body`; a push onto the closed queue raises through it** (`P8-53`) so that `Net::HTTP` closes its own socket on the way out — a `break` leaves a half-read keep-alive connection open, and on a borrowed started client the next request would read the remainder as a corrupt status line. Measured: a borrowed 200 kB response closed after ten bytes, then a second request through the same started client, reads 200 000 bytes.
